# サブスク＆固定費一括管理・削減シミュレーター

受講番号：6th-11
氏名：大坪和歩

## 1. プロダクトの紹介

Docker（Laravel Sail）環境で構築した，サブスクリプションおよび固定費の一括管理・削減シミュレーションアプリケーションです．

- 契約中のサブスクや固定費を一覧で一括管理・可視化できる
- 並び替え機能（新しい順，古い順，料金が高い順，料金が安い順）により，支出の把握がスムーズに行える
- カテゴリ別の支出割合を円グラフで一目で確認できる
- 一覧のチェックボックスを選択することで，削りたいサービスを解約した場合の削減見込み額をリアルタイムでシミュレーションできる

このプロダクトを選んだ理由は，月額・年額が混在する固定費を直感的に整理し，削減効果を視覚化し、支出を抑えるWebアプリを作成したいと考えたからです．

## 2. こだわった点・苦労した点

- 画面の視認性を高めるため，絵文字や装飾用アイコンを排したクリーンなUIデザインを採用した
- Chart.js を導入し，カテゴリごとの支出割合を円グラフで分かりやすく表示した
- 一覧のチェックボックス操作に応じて削減見込み額が即座に計算されるJavaScript連携を実装した
- MassAssignmentException や UniqueConstraintViolationException などのエラーが発生したが，モデルの $fillable 設定や DatabaseSeeder の記述およびマイグレーション処理を見直すことで解決した

## 3. 操作方法

1. 新規登録フォームからサービス名・カテゴリ・料金・周期（月額/年額）・次回更新日を入力して「登録する」ボタンを押す
2. 契約一覧画面右上のドロップダウンから「新しい順」「古い順」「料金が高い順」「料金が安い順」を選択して並び替えを行う
3. 一覧の左端にある「削減対象」チェックボックスにチェックを入れ，画面上部の「シミュレーション削減可能額」がリアルタイムに更新されるのを確認する
4. 不要になった項目は「削除」ボタンを押して削除する
